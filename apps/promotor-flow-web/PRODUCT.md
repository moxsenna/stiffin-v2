# PromotorFlow — Product Specification

## 1. Product Purpose
PromotorFlow is the **Daily Pipeline & Lead Follow-Up Execution OS** tailored specifically for certified STIFIn Promoters and branch operators. It eliminates manual lead loss on WhatsApp by converting incoming inquiries and PromotorClass learning signals into an actionable 1-tap WhatsApp queue, 14-day booking calendar, and automated D+7 aftersales retention engine.

## 2. Target Users
1. **Certified STIFIn Promoters (Individual Operators & Educators)**: Run personal mentoring, family tests, and parenting consultations.
2. **STIFIn Branch Managers & Admins**: Coordinate multiple promoter schedules, manage client booking pipelines, and track conversion rates.

## 3. Core Mechanisms & Capabilities
- **Today Action Queue**: Priority-ranked tasks categorized by Overdue, Today Schedule, and Upcoming follow-ups.
- **1-Tap WhatsApp Launcher**: Context-aware template generation with instant `https://wa.me` dispatch and delivery confirmation.
- **14-Day Dynamic Availability & Booking Link**: Client self-scheduling with automatic session lock.
- **Intelligence Signal Stream**: Real-time integration receiving intent triggers from PromotorClass (completed modules, reflection submissions, CTA clicks).
- **Automated D+7 Aftercare Retention**: Scheduled post-test engagement to drive family referrals and follow-on programs.

## 4. Operating Context
- **Primary Form Factor**: Mobile-first Web/PWA (promoters manage leads on-the-go via mobile) with responsive desktop split-pane support.
- **Network Resilience**: Instant optimistic UI with local persistence and background server synchronization.

## 5. Product Principles
- **Action Over Admin**: Every screen prioritizes the next WhatsApp action rather than complex data entry.
- **Zero Hallucinated Leads**: Every contact and action is rooted in verified E.164 phone numbers and timestamped interactions.
- **High-Velocity Ergonomics**: 48px touch targets, sticky bottom navigation dock, and zero cognitive drag.
